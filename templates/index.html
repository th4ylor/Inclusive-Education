Metodologias de estudo

Qual formato você quer
experimentar hoje?

Experimente ciclos de 15, 25 ou 50 minutos, com pausas entre eles. Para revisar o conteúdo, siga os roteiros da Técnica de Feynman e da repetição espaçada.

% Foco

Pomodoro

Divida o estudo em períodos de 25 minutos, com pausas de 5 minutos para descansar antes de continuar.

Como funciona
  1. Escolha uma tarefa para este ciclo.
  2. Dedique os próximos 25 minutos à tarefa escolhida.
  3. Faça uma pausa de 5 minutos.
  4. Ao terminar a pausa, decida se quer começar outro ciclo.
% Foco

Foco Curto

Sessões de 15 minutos, com pequenas pausas. É uma forma de começar quando uma sessão longa parece cansativa.

Como funciona
  1. Escolha uma tarefa pequena para começar
  2. Dedique 15 minutos à tarefa escolhida.
  3. Descanse por 3 minutos
  4. Depois da pausa, escolha se quer continuar.
% Foco

Estudo em blocos

Reserve 50 minutos para se dedicar a um conteúdo, seguidos de 10 minutos de descanso. Esse formato oferece mais tempo para desenvolver uma atividade.

Como funciona
  1. Escolha uma atividade para este bloco.
  2. Dedique os próximos 50 minutos à atividade escolhida.
  3. Faça uma pausa de 10 minutos.
  4. Depois da pausa, decida se quer iniciar outro bloco.
% Foco

Tecnica de Feynman

Explique o que aprendeu com palavras simples. Ao tentar ensinar o conteúdo, você percebe quais partes entendeu e quais ainda precisa revisar.

Como funciona
  1. Escolha um assunto que deseja entender melhor
  2. Explique o assunto para alguém que ainda não o conhece.
  3. Anote os pontos que você não conseguiu explicar.
  4. Consulte o material nesses pontos e tente explicar novamente.
% Foco

Repetição Espaçada

Retome o conteúdo em dias diferentes, aumentando o intervalo entre as revisões conforme se sentir mais seguro. O roteiro ajuda a conduzir a revisão, e você organiza as próximas datas.

Como funciona
  1. Escolha um conteúdo que você já estudou e tente lembrar dele antes de consultar o material.
  2. Identifique o que lembrou com facilidade e o que precisa rever.
  3. Escolha a próxima data de revisão. Retome antes os pontos que foram mais difíceis de lembrar.

Uma sequência para experimentar

Escolha uma tarefa. Estude por 25 minutos. Faça uma pausa de 5. Depois, revise algumas perguntas com flashcards. Você pode encerrar por aqui ou começar outro ciclo.

Apresentação da equipe

O SenFlow é uma aplicação web desenvolvida por quatro estudantes da UNA Divinópolis para a disciplina de Algoritmos e Programação. Com o tema Educação Inclusiva, o projeto integra ferramentas de estudo, autenticação de usuários, persistência de dados e hospedagem na Amazon EC2

Desenvolvimento Front-end

Alexsander Sales

Desenvolvi a interface do painel inicial, utilizando HTML para estruturar o conteúdo, CSS para definir a apresentação visual e JavaScript para implementar as interações. Também organizei a navegação entre as ferramentas da plataforma.

Desenvolvimento Full Stack

Isaak Thaylor

Desenvolvi a página de apresentação e o módulo de flashcards, integrando a interface às operações de criação, consulta e revisão dos cartões. Também configurei a hospedagem na Amazon EC2 e realizei a publicação da aplicação.

Desenvolvimento Back-end

Cristopher Oliveira

Desenvolvi o módulo de metodologias de estudo, implementando o controle dos ciclos de foco e pausa, a navegação entre etapas e o acompanhamento das sessões. Integrei a interface às rotas responsáveis por iniciar, pausar, retomar e encerrar cada sessão.

Banco de Dados

Icaro Fernandes

Desenvolvi o módulo de Post-its, com operações de criação, consulta, edição e exclusão de anotações. Também implementei o cadastro e o login, incluindo validação dos dados, armazenamento de senhas com hash e controle de autenticação por sessão.
